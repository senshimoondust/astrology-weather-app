# astrology-weather-app

🌙 Astrology Weather App

A front-end weather application that displays real-time weather data using a public weather API, wrapped in an astrology-inspired visual theme. While the design leans cosmic, the functionality is rooted in real meteorological data—combining creativity with practical JavaScript development.

⸻

✨ Features
• ☀️ Real-Time Weather Data
Fetches current weather conditions using a third-party weather API.
• 🌡️ Temperature, Conditions & Location
Displays temperature, weather description, and city-based results.
• 🔍 Search by City
Users can search for weather information by city name.
• 🌙 Astrology-Inspired UI Theme
Cosmic colors, typography, and icons used for visual branding only.
• 📱 Responsive Design
Optimized for desktop and mobile screens.

⸻

🛠️ Tech Stack
• HTML5 – Semantic markup
• CSS3 – Custom styling and responsive layout
• JavaScript (Vanilla JS) – DOM manipulation and API handling
• APIs – Weather data (e.g., OpenWeatherMap)
